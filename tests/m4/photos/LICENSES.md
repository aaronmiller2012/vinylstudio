# M4 benchmark photographs

All files were downloaded from the scikit-image 0.19.3 data set
(`https://raw.githubusercontent.com/scikit-image/scikit-image/v0.19.3/skimage/data/`)
and verified against the SHA-256 values in that release's `skimage/data/_registry.py`.
License statements are quoted from `skimage/data/_fetchers.py` at the same tag.

| File | Benchmark role | License (as stated upstream) |
|---|---|---|
| astronaut.png | Portrait: skin texture, facial detail, colour (Eileen Collins, NASA) | Public domain (NASA) |
| camera.png | High-contrast black-and-white figure | CC0, photographer Lav Varshney |
| chelsea.png | Detailed textured animal (cat fur, whiskers) | CC0, photographer Stefan van der Walt |
| coffee.png | Colourful scene with several distinct objects | CC0, photographer Rachel Michetti |
| rocket.jpg | Subtle highlights and shadows, sky gradient | Public domain (SpaceX release) |
| gravel.png | Fine pattern, complex boundaries | CC0 (CC0Textures Gravel04) |
| moon.png | Dark, low-contrast photograph | "No known copyright restrictions" |
| horse.png | High-contrast silhouette (binary) | CC0, owner Andreas Preuss |

Gap: no license-clear portrait **with eyeglasses and loose hair strands** was available
from a verifiable source. That benchmark slot is unfilled; reviewers should add a
project-owned photograph before judging eyeglass-frame continuity.
